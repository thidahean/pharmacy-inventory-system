# 🏥 NR1 Pharmacy Inventory System

A complete web-based pharmacy inventory management system built with PHP, MySQL, and Docker.

![NR1 Pharmacy](https://img.shields.io/badge/NR1-Pharmacy-purple)
![PHP](https://img.shields.io/badge/PHP-8.2-blue)
![MySQL](https://img.shields.io/badge/MySQL-8.0-orange)
![Docker](https://img.shields.io/badge/Docker-Compose-blue)

## 📋 Features

- 🔐 **Login System** — 3 user roles (Admin, Pharmacist, Cashier)
- 📊 **Dashboard** — Real-time statistics with charts
- 💊 **Product Management** — CRUD operations for medicines
- 🏷️ **Categories** — Manage medicine categories
- 🚚 **Suppliers** — Manage supplier information
- 🛒 **Sales (POS)** — Point of sale with auto stock deduction
- 📈 **Reports** — Sales analytics and top products
- 🌙 **Dark/Light Mode** — Theme toggle with localStorage

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | HTML5, CSS3, JavaScript, Chart.js |
| Backend | PHP 8.2 |
| Database | MySQL 8.0 |
| Server | Apache |
| Container | Docker + Docker Compose |
| Dev Env | WSL2 (Ubuntu) + VS Code |
